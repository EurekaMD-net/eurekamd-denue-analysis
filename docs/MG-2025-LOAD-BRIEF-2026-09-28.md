One-off `ogr2ogr` into `public.<layer>_polygons`, reprojected on the fly with
`-t_srs EPSG:4326 -nlt PROMOTE_TO_MULTI`; only record is the comment in
`scripts/backfill-ageb.ts:4-24`. Layout = ogr2ogr PG defaults (`ogc_fid`
serial PK, lowercase varchar columns, `geom geometry(MultiPolygon,4326)`,
GiST), `<t>_cvegeo_uq` from `scripts/migrations/020-indexes.sql:66-73`,
`idx_ageb_polygons_ent_mun` from `ops/deploy-audit-refactor.sh:113`. 22
invalid AGEBs repaired with `ST_Multi(ST_CollectionExtract(ST_MakeValid(geom),3))`
(`019-censo-views-treemap-geoms.sql:268`). No simplification. Live counts:
`mun_polygons` 2,469 · `ageb_polygons` 81,451 · `loc_polygons` 50,308 ·
`ent_polygons` 32. Ledger row id 8 `marco_geoestadistico | MG 2020`.
Grants today: `denue_api` SELECT on ageb+mun only; `denue_sage` revoked;
`*_ogc_fid_seq` sequences still grant anon/authenticated rwU (legacy, fix
separately); the `postgres` default ACL gives `trustr_app` full rights on
every new table → revoke right after create.

Diff 2025 vs live: municipios 9 new / 0 removed / 12 renamed; AGEB 81,036
shared / 1,247 new / 415 gone.

## Proposal

Tables `mun_polygons_2025`, `ageb_polygons_2025` (optionally
`ent_polygons_2025`, `loc_polygons_2025`). Never `-overwrite`/`-append` on
the 2020 names.

```
ogr2ogr -f PGDUMP /vsistdout/ \
  "/vsizip//vsizip/raw/mg2025/794551163061_s.zip/mg_2025_integrado.zip/conjunto_de_datos/00mun.shp" \
  -nln mun_polygons_2025 -lco SCHEMA=public -lco GEOMETRY_NAME=geom -lco FID=ogc_fid \
  -lco SPATIAL_INDEX=GIST -lco CREATE_SCHEMA=OFF -lco DROP_TABLE=OFF \
  -nlt PROMOTE_TO_MULTI -t_srs EPSG:4326 \
| docker exec -i supabase-db psql -U postgres -d postgres -v ON_ERROR_STOP=1 --single-transaction
```

Same for `00a` → `ageb_polygons_2025`. Encoding from `.cpg`; confirm
`Dzitbalché` / `Ñuu Savi` survive. Post-load, same session, packaged as a
migration: owner postgres + REVOKE anon/authenticated/trustr_app (tables and
`_ogc_fid_seq`); `<t>_cvegeo_uq`; `(cve_ent, cve_mun)` index on AGEB;
`ST_MakeValid` repair + `ANALYZE`; `COMMENT ON TABLE` with UPC + sha256.
